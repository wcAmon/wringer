## (d) 名詞表

- **蓄水 / 排水 / 水庫**:E37 起的兩段機制。**蓄水**=量化碼全凍,掛低秩旁路(r128,B_rA_r)對 bf16 老師做 KD(res_fill),把「量化失去的功能」暫存在連續載體裡;**水庫**=該旁路(res_*);**排水**=凍結旁路,逐窗把水位 γ 由 1 降到 0,用 solver(comp 事件)把水吸收進碼/α/θ(train_res 五格水位閉環 τ/W_max)。裁判點 A=蓄水天花板,B=排水後。
- **閉式排水**:E64 起不用逐窗訓練,直接以 Σ-加權最小二乘把「碼+水」的 W_eff 閉式重擬合成 α(scale_joint)、逐元非對稱重投影與 2 bit r(asym_mix / quantize --base-dir),零訓練吸收;E65-X 後必加先驗(prior=舊 α,λ=0.01)。
- **帳面 / 純碼**:**帳面**(bpw、b/w)=推論時實際落盤的位元帳(碼熵+α+r+載體);**純碼**=推論態只含碼+α(無 LoRA/M/L 常駐載體),水全排為鷹架。「同帳」=與 GGUF 主幹(blk.* 線性層)口徑對齊後內插比較。
- **翻碼(flip)**:訓練/求解中離散碼 T 改變的比例(t_flip、net_flip、agree_g3)。e2e 打磨 flip≈0(只動連續軸);逐窗段 flip 大;E58R1b 顯示 he ρ 隨翻碼量單調降。
- **材化(export/materialize)**:把「碼+α+旁路/旋轉/M」折成 dense HF 權重供 vLLM 評測(export_rot 的 W_q·Qᵀ、--strip-mix 等),須過等價閘(rel≈0)。
- **甲 / comp**:E45 起的主判=三科(IFEval strict / HumanEval / GSM8K)對 bf16 錨(w128 座標 92.79/94.51/95.53)之回復率等權平均;乙=最短板回復率(監測);雙跑均值制(噪音 ±0.016)。
- **U 曲線**:E67 起以 llama.cpp UD 式 GGUF(imatrix,保護 ssm_out/attn_v)量化的對照曲線,點 U25/U27/U30/U34(主幹 2.558/2.763/2.972/3.295 bpw;comp 0.3216/0.7547/0.8955/0.9855);J_P/J_C=我方點對 U 曲線同帳內插之差。
- **北極星**:階段性最終目標。E62b 後=「三元碼單獨 comp ≥0.90」;09-08 用戶改寫=「IQ2_M 級(~2.7 bpw)comp ≥0.90」;E68 首次跨越(0.9695 @3.206),E69 於 2.655 純碼達成(0.9365)。
- **冠軍**:各時期主判下的現任最佳態(export 保留、其餘死臂可刪)。譜系:E32 44.55 → E37 50.28 → E39 54.90 → E40 70.43 → E41 72.27(IFEval)→ e42b_r1 0.6677 → st47d_e2e 0.6982 → st47d_hec_e2e 0.7055 → st51c_e2e 0.7469/均值 0.7388(甲)→ pa64_asymrefitq2 0.8235(零訓練 2.70 bpw)→ p1alpha 0.9799 @3.206 → p3b_w 0.9365 @2.655(北極星)。
- **哨兵(Monitor)**:長鏈以 nohup setsid 脫離後,用 Monitor 工具盯 log 的預註冊事件字串(E37_*_DONE、E69S3_A 等),收卷動作在快照中預寫;禁止 Bash waiter、管線末端勿加 cut、pgrep 用 bracket 防自匹配。
- **falsifier(殺閘)**:prereg 內先寫死的否證條件(如 ρ<0.70、he<存續線、triage<55),觸發即封盤該軸,不回問。
- **ρ(保留率)**:排水保留率 ρ=(B−floor)/(A−floor) 或 B/A(A4 台上 ρ=comp/0.7038);ρ_if/ρ_he 分科;E37 0.969、E38 0.485、E57 0.870、E58R1 0.748、E61c 0.889、E69 S3 1.47(B>A,閉式吸收);ρ_conv=E59 轉換保留率(分母 G9_FLOOR 0.9226)。
- **α / β / r 帳項**:**α**=每 group(g32/g16/g128)的尺度(fp16 0.5 b/w @g32;int8/g128 更省);**β**=T2 位面的獨立係數(w=α·T1+β·T2,E63 T2β)或第三中心(codex F8,已封);**r**=每 block 2 bit 負側比例(非對稱三元 {−rα,0,+α},+0.0625 b/w),E63 起;另 **r128/r256/r512**=水庫 LoRA rank。
- **g128 / g32 / g16**:α 分組粒度(每 128/32/16 個權重共用一個 α)。g32=三元期控制變因;半 g16(深層 24–31)=E48b 定的三元位元政策 3.63 b/w;g128 fp16 α=E68 帳面對齊的關鍵(α 開銷 0.5→0.125 b/w)。
- **八元 / 四元 / 三元 / 九元(2/4/8/9 級)**:碼格點數。三元 {0,±α};九元=k=2 加法位面 W=α⊙(T₁+c·T₂),c=0.6(嵌套 3⊂5⊂7⊂9);八元留零 {−4..3}(E68,丟極值+α 負號方向位);四級 {−2..1}(E69,2.0 b/w,用於 z/qkv/gate/out 等張量)。
- **on-manifold 語料**:以 bf16 老師自身(vLLM)在真 chat 模板+考場採樣下生成的軌跡(cal4→cal10→e58r1b 16k),學生只在老師分佈上蒸餾;E39 起為標準;bleachers=Max/DeepSeek 出題+程序驗證的題庫。
- **閉合加權(λ_close)**:E51 起在 KD loss 中對 `</think>` 閉合 token 及其後 k 個 token 加權(256/16×8 或 32/16/8),治「思考不終止→空回應」失律;res_fill 於 E69 亦支援。
- **proxy 反轉**:訓練側代理(val CE、窗 loss、局部重建誤差、KD、churn)與官方能力分數方向相反或不映射;共 18 筆/多型在案,紀律=一切訓練側曲線 monitor-only、裁決只認官方三科。
