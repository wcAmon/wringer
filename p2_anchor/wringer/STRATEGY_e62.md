## 1. 兩支零訓練探針的結論(@c892036 容量階梯、@555428f 側向/解剖)

### 1.1 桶的大小不是主因
- bd128 桶對終態碼**離線重解**平均再吸 16%(K=9216 down_proj +33%、K=2560 +7%),ridge 五檔同值 → 不是求解器自限,是 **M 對終態碼滯後**(最後一次 LS 事件後,翻碼與 14 ep 尾段又動了碼)。L22 down_proj 現 M 甚至劣於單位矩陣(−27%)。
- 結構階梯(輸入側):bd256 +22% / bd512 +29% / 全密 +44%(全密在 down_proj 參數多於權重,是過參數上界,不可部署)。
- 雙層:Monarch(bd128·跨塊同位耦合)+20% @0.60 b/w,達 bd256 九成、成本七成 → 過門檻;蝶形對角 +16% 不過。收益集中在 down_proj。

### 1.2 桶的位置比大小重要
| 模組 | 輸入側 X 重解 | 輸出側 L(塊 128) | L+X | Monarch | X 成本 | L 成本 |
|---|---|---|---|---|---|---|
| down_proj(8 層均)| +39% | +31% | +46% | +45% | 0.80 b/w | **0.22 b/w** |
| in_proj_qkv(2 層)| +12% | +38% | +47% | +14% | 0.25 b/w | 0.80 b/w |

規律:**大邊桶多、小邊便宜**。down_proj 是唯一輸入比輸出寬 3.6× 的模組,輸出側 L 用 0.22 b/w 拿到輸入側八成吸水,L+X 與 Monarch 同效但便宜 2.7×。int8 存 L/X 零損;int4 平均 0.70(down_proj 0.93);**三元化 M 全負,M 不能壓三元**(位元帳分開記:三元碼 1.58 + 連續載體 int8)。

### 1.4 對「深層加大 M」的答案
不按深度均一放大。深層 down_proj 的問題是 M 滯後(可修)與補償記帳(非 M 能修)。結構上值得加的是 down_proj 輸出側 L,不是更大的輸入側塊。

## 2. 決策樹(E62a 不是 E62b 的前提,是它的校準器)

E62a 與 E62b 修的是兩個正交的東西:a 修**時機**(M 對哪個時刻的碼負責),b 修**位置**(桶放哪一側)。a 先跑不是因為 b 要等 a 過,而是:
1. a 零位元、零結構,結果只有一個變因;
2. a 的官方讀數校準「局部吸水 → 官方分數」在 M 軸上的轉換率,決定 b 的預期值是否值得付 0.11 b/w。

```
E62a 窗尾重解(st61c 引擎 + 尾段後 LS 一次 + holdout 回退閘)→ 官方 ρ 對 st61c 0.889,票帶 ±0.016
├─ PASS(ρ ≥ 0.90;0.905 起同時為 POS)
│                          → S2 立即以 E62a 引擎兌現(冠軍蓄水→A 閘→排水→B vs 0.7469)
│                            E62b 排在 S2 之後,作引擎 v2 在 A4 台上測,POS 才升級 S2 引擎
├─ NULL(0.873 ≤ ρ < 0.90) → E62b 疊在 a 上(a 零成本、局部效應真實,NULL≠有害);a+b 對 st61c 裁,PASS → S2
└─ NEG(ρ < 0.873)         → 回退閘失守 = 窗尾重解本身傷官方(第 12 型);撤 a,E62b 單獨對 st61c 裁
```

E62b 之後:
```
E62b(down_proj 輸出側 L,塊 128,int8,每事件 L/X 交替 LS;+0.11 b/w)
├─ PASS 或 POS → S2 引擎升級;Monarch 回歸探針(§3)
├─ NULL        → 位置軸封盤;S2 用當時最佳引擎;剩餘候選轉 he 軸 / mix_lr=0
└─ NEG         → L 撤;同上
```

## 3. Monarch 何時回來

Monarch 是「輸入側第三桶」。它回來需要三件事同時成立:
1. E62b 已裁 POS 以上(證明 down_proj 上「局部吸水 → 官方」轉換率為正;否則任何再加桶都是盲投)。
2. **回歸探針**(零訓練,6 min):在 E62b 終態上量 L+X+F(Monarch F)對 L+X 的邊際;門檻 down_proj 平均 ≥ +0.10、且 L+X 後殘水/原水仍 > 0.5 的層 ≥ 一半。
3. 位元帳:F int8 +0.38 b/w(down_proj 專用時攤到全模型 +0.09)。合計 M 系列 ≤ 0.35 b/w 全模型(三元本體 1.58 的 22%)為上限,超過不做。

不回來的條件:E62b NULL/NEG,或回歸探針邊際 < 0.10。qkv 的 Monarch(+13%)永久出局;qkv 的桶在輸出側但 0.8 b/w 太貴,列為「位元預算放寬時」的後補。
