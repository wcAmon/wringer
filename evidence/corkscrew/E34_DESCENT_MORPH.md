# E34 立案:訓練驅趕降元(grid morphing descent)

狀態:**主路徑,未 prereg**。用戶裁定並再確認(2026-08-11):訓練驅趕
+刻度成形是降元階梯 9→7→5→3 的**主要路徑**——這正是階梯策略存在的
理由(從頭量化的可行性隨檔位崩潰:9元 97.4% / 混元 49% / 3元 39%)。
正式 prereg 待 E33 收卷數據(flip/gdisc 軌跡)定 morph 排程後凍結。

**偏離承認**:E33 把從頭 GPTQ 放在 MAIN 臂、把降元路線降為條件分岔
(且僅硬投影),是工程慣性壓過綱領靈魂的便宜行事,經用戶指正糾正。
E33 MAIN 自此**重新定位為「從頭量化對照臂」**——它測的是階梯假說的
虛無假設,是 M1 判準的分母,不再是主線。

---

## 1. 動機:現有兩條降元路線都是「先斷後修」

| 路線 | 刻度何時強加 | 26.87% 的 ±0.4 質量怎麼處理 |
|---|---|---|
| 從頭量化(E33 MAIN) | GPTQ 一次到位 | 從未存在,GPTQ 逐列補償後訓練修復 |
| 硬投影(arm B,未跑) | 投影瞬間 | 最近距離規則一刀驅逐(硬投影 RMS 12.43%) |
| **形變(本案)** | **從不瞬間強加** | **訓練壓力下逐 epoch 自己選邊** |

診斷依據:9元 的 ±0.4=±(1−c) 兩格是**所有非零格中佔用最高**的
(各 13.4%,DIAG_ZEROGPU A 節);7元 恰好砍掉它們。任何瞬間強加
方案都讓這 26.87% 的質量在單步內被指派,訓練只能事後救。

## 2. 主機制:c 滑移即降元(已數學驗證,`morph_check.py`)

9元 值集 {0, ±(1−c), ±c, ±1, ±(1+c)} 有一個內建的合併機制:
**c→0.5 時 ±(1−c) 與 ±c 相撞**(`grid_tensors` 的退化 assert 證實)。
因此降元不需要任何離散切換——**把 c 從 0.6 連續滑到 0.5 就是 9→7**:

- 消失階((1−c) 與 c 之間)高度 = 2c−1,隨滑移平滑歸零;
- 門檻極限 {±0.25, ±0.75, ±1.25} 恰為均勻 7元 c=0.5 的門檻;
- 終點恰為族內最優網格(diag_gridc:c=0.505 均勻),**驅趕與刻度
  成形是同一個動作**;
- 住在 ±0.4 盆地的權重(bf16 質量 25.14%)在盆地滑移+收縮中被
  訓練壓力驅趕選邊,而非被最近距離規則一刀切。

CPU 驗證(morph_check,@commit):V1 階梯對 c 連續;V2 逐點收斂
且偏差恰為 c−0.5;V3 恆等極限沿全程成立(Σh_jθ_j=0 不破,G-disc
照常監測);V4 零訓練 null 流向 = 直接投影:盆地質量 81.8%→±0.5、
18.2%→0——**訓練臂流向與此偏離即 M3 的機制證據**。

### 2b. learnable c 的三態生命週期(用戶設計,08-11)

c 不是常數,是**階梯訓練的可學形狀參數**,分三態:

**態一:檔位內自由學習(LSQ 式)。** 固定檔位訓練(含多次逐窗退火)
期間 c 逐模組可學——網格形狀由訓練自然發現,c* 從手調超參變成
**量測輸出**(9元 會學到哪裡?MSE 先驗說 0.66,任務 loss 說了算)。
c∈固定象限內(如 (0.5,1))值序不變,h(c)、θ(c) 閉式可微,autograd
直通。與 δα 可學並存:α 管整體尺度、c 管兩累加器的形狀比,可辨識。

**態二:降元走廊(合併瞬間必須課程強制)。** 兩階合併是損失上升
方向,梯度永不自願走(9元 MSE 梯度指向 0.66,背對 0.5)——這是
「驅趕」與「自由優化」的分界。走廊公式:

    c_module(m) = c_target + (c_free − c_target) · 2σ(logit_module)

m→1 時排程把括號收零,終點精確夾到 c_target,優化器只學步伐。

**態三:收歸 α(3元 終局)。** 3元 值集 {0,±1}·α **沒有 c**——
T₂ 消滅,W = α·T₁。一路學到的全部網格幾何在最後一次 finalize 由
joint-α 重解吸收進 scale。**c 是訓練期輔助參數,最終零儲存成本**,
中間各級的逐模組 c 也只是暫態(部署合法但不必長存)。

**全階梯碰撞代數**(值集 {0,±(1−c),±c,±1,±(1+c)} 的內建合併點):

| 降元 | 機制 | 走廊 |
|---|---|---|
| 9→7 | ±(1−c) 撞 ±c | c: c*₉ → 0.5 |
| 7→5 | ±(1+c) 併 ±1(c 無碰撞點可用) | 外側 threshold-merge(2c 節) |
| 5→3 | ±c 撞 0 | c: c*₅ → 0 |
| 3元 | c 消滅 | 幾何全收進 α |

7→5 是唯一要用備選機制的一級(1+c→1 需 c→0,但 c→0 同時殺 ±c,
會直接 7→3 跳級——除非未來實驗顯示跳級可行,則 c:0.5→0 一條走廊
直達 3元,5元 一級整個省略,此為開放問題)。

### 2c. 備選:threshold-merge(僅當終點須留在 c=0.6 時)

若某級降元的終點被迫保持 c=0.6(例:未來某級嵌套約束回歸),則改用
門檻合併:包夾被砍值的兩個門檻隨 m 滑向共同點,值集不動、盆地寬度
歸零。機制等價但多一組排程參數;7元 一級用不到(c 滑移嚴格較優:
同時抵達均勻網格)。

## 3. 課程排程(與 s 退火的疊加)

起點 = E33 PRE 兩迴中**官方裁判較好者**(用戶規則 08-11):st9 與
st9s2 兩 state 各自硬導出(不經 e2e,隔離第二迴單一變因)→ 同台
IFEval → 勝者為 morph 的 9元 起點(~1.2h,收卷後執行)。此比較
同時給 Z3 一個無語料混淆的替代裁決(官方座標,取代窗 loss 中位數
——原 Z3 判準照舊執行並揭露混淆,此處為加測不改 prereg)。

每窗內三段(窗序照舊淺→深):

```
epoch:   [0 ─ plateau ─)[── morph ──)[── 硬化 ──]
s:        2.0 鎖定        中低 s 緩升   直衝 s0
m:        0(純 9元)      0 → 1 線性    1(純 7元)
```

原則:**m 的變動必須發生在 s 還低的區間**——盆地收縮要在梯度還能
流動時進行,否則退化回硬投影。硬化段只做已定形 7元 網格的承諾。
具體切點(morph 起訖 epoch、與 plateau_frac 的關係)等 E33 的
flip/gdisc 軌跡定,prereg 時凍結。

可選疊加(第二階段,非首發):morph 完成後對仍貼門檻的權重做
TesseraQ 式信心分批凍結(E34 候選箱既有項)。

## 4. 實作點(全部在既有結構上)

1. `SoftGrid`:加 `set_c(c)` 重建 (vals, θ, h)(直接呼叫
   `grid_tensors(9, c)`,c∈(0.5, 0.6] 全程 9 值合法;morph_check 已
   驗 assert 沿途成立)。終態落盤用 `grid_tensors(7, 0.5)`。
2. `STQParam`:加逐模組 `c_param`(態一自由學習;態二切走廊公式,
   logit 學步伐);c 進 forward 需 h(c)、θ(c) 可微重建(值序固定
   象限內閉式,不能走 grid_tensors 的 python sort)。
3. `train_st`:加 `--learn-c`(態一)與 `--morph-to 7 --morph-lo E1
   --morph-hi E2`(態二走廊);finalize 段以 7元 c=0.5 投影落盤。
   注意 state 落盤格式需帶終態 c(下游 load_state/e2e 讀 c=0.5,
   不能再默認 C_K2=0.6);若逐模組 c,落盤逐模組。
4. 記錄新診斷量:**被驅逐質量流向分佈**——morph 前住在 ±0.4 格的
   權重,終態落到 {0, ±0.6(或±0.5), 其他} 的比例。這是「驅趕 vs
   一刀切」機制差異的直接觀測,硬投影的對照值可由 diag_proj7 免費
   算出(最近距離規則的流向是確定的)。

## 5. 判準草案(prereg 前身,凍結前可改)

- 對照臂 = E33 MAIN(從頭 GPTQ 7元 + 同款雙迴配方,c=0.6)。
- M1(主):morph 臂 IFEval strict > E33 MAIN,且 ≥ 0.90×bf16
  (與 Z2 同 floor 0.81848)。
- M2(懸崖):humaneval 保留 ≥ 85%(四科錨定 @ab0adc5 協定)。
- M3(機制):被驅逐質量的流向分佈顯著異於硬投影的最近距離流向
  (否則「驅趕」沒有發生,只是慢動作投影)。
- M4(穩定):V5 帶化與 Z4 同款判準;G-disc 無異常。
- 預算聲明:morph 臂總算力 = 9元 訓練(沉沒,復用)+ 1 morph sweep
  (~4h)+ e2e + eval;高於對照臂,判讀時須連同聲明。

## 6. 與 E33 分岔的關係

- E33 Z2 PASS(7元 從頭已達 90%):morph 案改測 7→5(下一級的
  ±(1−c)… 5元 砍的是 ±1±… 依 grid_tensors(5) 值集另算佔用)。
- Z2 驚險敗:c=0.5 從頭重試(既有分岔)與 morph 案並行比較。
- Z2 大幅敗 + flip 早凍:morph 案為 E34 首選(搜索受限,課程軸
  正中靶心)。
- Z2 大幅敗 + flip 充分:容量牆證據,morph 期望下修——但它仍是
  唯一未測過的降元方式,且復用 st9s2 使邊際成本僅 ~5h。

## 6b. 走廊實作紀錄(as-built,@fc4cf79/@9a9b02d,收卷 @3acf529)

首戰(E34 9→7)實際落地的設計,與 §2b 的對應與偏差:

**走廊機制(stq.py)**:
- `STQParam.enable_morph(c_tgt=0.5, to=7)`:建逐模組標量
  `logit_c`(nn.Parameter,init 0 → 2σ=1 → c 沿排程走);記
  `_c_free=0.6`、`_m=0`。
- `set_m(m)`:每 epoch 由 train_st 廣播;**已收斂參數 no-op**——
  win=2/stride=1 下每層在首次入窗完成形變,次窗以 7元 續訓,
  重疊語義自動正確。
- `_collapse()`(m≥1 觸發):切 `SoftGrid(n=7, c=0.5)`、`self.c=0.5`;
  **dθ 不重建參數,走索引遮罩 [0,1,3,4,6,7]**(9元 門檻 idx 2/5 隨
  h→0 消失;Adam state 綁參數物件,mid-training 重建會炸優化器)。
- soft 前向:`corridor()` 算 c(m) → `grid_from_c(9, c)` 閉式 θ/h
  (autograd 直通 c)→ `soft_staircase_c`;dθ 偏移以 h(c) 縮放,
  消失階的偏移自動歸零。
- 防禦:`extract` 斷言不得在走廊中途呼叫;`_hard_ste` 中途版用
  detached c 現建網格(實際課程中不會走到)。

**課程(train_st,prereg @88d622d)**:30 epoch/窗;平台 0.3
(ep 0-8 s=2)、走廊 [2,8] 線性(全程在 s=2 平台內=梯度最大流動
區)、s 退火 ep 9-26(2→30)、STE ep 27-29。冒煙時走廊自動縮 [0,1]。

**下游 c 語義**:state 逐模組落 c=0.5/grid=7;export/train_st resume
原生正確;**e2e_soft 曾有 C_K2=0.6 默認洩漏,@9a9b02d 修為 grids
以 (grid,c) 為鍵**——任何新下游都要審這一條。

## 6c. M3 未證與走廊排程改進候選(下次降元實驗的旋鈕箱)

M3 實測:盆地(±0.4 格,9.55 億權重)流向 to_half 0.8413 /
to_zero 0.1587 / to_other 0;null(最近距離投影)= 0.818/0.182。
方向偏驅趕(多推 ±0.5、少送 0)但 |Δ|=2.33pp < 3pp 凍結門檻——
**流向統計上無法區分「驅趕」與「慢動作投影+訓練修復」**。M1 與
M3 獨立:降元成功,機制敘事未證。

改進候選(按嫌疑排序;M1 已過,這些是機制實驗,非救火):

1. **拉長走廊**:`--morph-hi 8→14`+`--plateau-frac 0.3→0.5`。
   消失階高度 2c−1 歸零速度減半,盆地權重有更多 epoch 在梯度下
   選邊。預測:流向偏離 null 隨走廊長度增大 → 證「之前滑太快」。
2. **凹形 m 排程**:線性 m 在走廊尾端(h≈0、梯度最弱)反而走最快
   ——改 `m = 1−(1−t)²` 讓尾端減速,合併最後一哩路慢走。
3. **延後起點**:`--morph-lo 2→5`,先給每窗純 9元 適應期(E33
   軌跡 loss 最低點在 ep 7-8)。
4. **s-耦合走廊**(結構性):m 綁 s 而非 epoch,程式保證「s<5 前
   收斂」,把約定變不變量。
5. **logit_c 消融臂**:凍 logit_c=0(純排程零可學)同課程重跑,
   裁「可學步伐」有無增益——目前無證據(見量測缺口)。

**量測缺口(下次必補)**:`_collapse()` 時未落盤各模組 logit_c
終值,「哪些模組搶先/滯後」的直接證據丟失。修法:collapse 前把
`float(self.logit_c)` 記進 state 或 rec(一行)。同理可記逐窗
collapse epoch 的 loss 跳升(collapse cost 曲線)。
