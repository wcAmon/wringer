## A 反號檔 26.87%:7元 砍掉的是佔用最高的非零格

E32 混元配置的 grid-9 層(28–31)格點佔用,c=0.6:

| 值 | (T₁,T₂) | 佔用 | |
|---|---|---|---|
| −1.6 | (−1,−1) | 5.80% | |
| −1.0 | (−1,0) | 10.51% | |
| −0.6 | (0,−1) | 10.39% | |
| **−0.4** | **(−1,1)** | **13.45%** | ← 7元 禁止 |
| 0.0 | (0,0) | 19.81% | |
| **+0.4** | **(1,−1)** | **13.42%** | ← 7元 禁止 |
| +0.6 | (0,1) | 10.37% | |
| +1.0 | (1,0) | 10.48% | |
| +1.6 | (1,1) | 5.78% | |

7元 的約束是 T₁·T₂ ≥ 0,砍掉的正是值 ±(1−c) = ±0.4 的兩格。
**它們是所有非零格中佔用最高的**(各 13.4%,高過 ±0.6 的 10.4% 與
±1.0 的 10.5%),因為 c=0.6 讓 ±0.4 落在「零之外密度最高」的位置。

grid-3 / grid-5 層的反號率恆為 0(表示本身不含反號格),故 E32 混元
整體的反號率只有 3.36%——這個全域數字沒有意義,必須分 grid 讀。

### 機制:α 正規化把異質性吸乾了

每 32 個輸入通道一個 α,而 α 由該 block 自己的 |W| 決定。通道間、層間
的尺度差異全被 α 吸收,剩下的只是 W/α 的**形狀**——而這個形狀在各處
幾乎相同。因此 9→7 的損傷不是某些通道的性質,是**網格幾何本身的性質**。

這同時解釋了 E32 已裁的「層級配置溢價否證」:不是層這個粒度選錯,是
**配置這條路本身沒有東西可配**。否證現已從層粒度推進到通道粒度。

**限制**:本量測是硬投影(未再訓練)的誤差,且未經 Σ 加權(Σ 只在量化
時即時收集、不落盤)。再訓練後的殘差有可能重新集中;Σ 加權也可能改變
排序。但「配置要有用,得先有東西可配」——硬投影階段已經沒有集中度,
配置方案要翻案就得證明再訓練會製造出集中度,舉證責任在提案方。

## D c 重優化:真實但很小(追加量測,`diag_gridc.json`)

C 指出損傷是網格幾何的性質,順勢量了幾何本身可改多少。方法:取 200 個
target linear 的 u = W/α₀ 經驗分佈(α₀ = TWN 逐 block 初始,35.7 億個
權重,clip 率 2.2e−5,E[u²]=0.7103),在 (c, s) 平面掃直接捨入 MSE,
s = 網格整體縮放(公平起見每個 c 都取自己的最佳 s)。

| 檔位 | 最佳 c | 最佳 s | 相對 RMS | c=0.6 相對 RMS | MSE 降幅 |
|---|---|---|---|---|---|
| 7元 | **0.505** | 1.08 | 21.55% | 22.13% | −5.2% |
| 9元 | **0.66** | 1.15 | 17.02% | 17.81% | −8.7% |

**最優 c 就是讓網格均勻的 c。** 7元 在 c=1/2 時值集 {0, .505, 1, 1.505},
間距 0.505/0.495/0.505 —— 均勻 7 階量化器;而 c=0.6 的間距是
0.6/**0.4**/0.6,中間那階窄了三分之一,白白浪費一個階。

9元 有結構性限制:值集 {0, ±(1−c), ±c, ±1, ±(1+c)},內部均勻需
1−c=h、c=2h、1=3h → c=2/3,但此時 1+c=5h 而均勻要求 4h。
**k=2 表示做不出均勻的 9 階網格**,最外兩階必然是離群點捕手。
實測最優 c=0.66 = 2/3,證實此代數。c=0.6 對 9元 已接近最優
(17.81 vs 17.02),對 7元 則明顯偏離。

**增益判定:小。** 折成 RMS 只有 2.6%(7元)與 4.4%(9元)的改善,
補回 9→7 落差(17.81→22.13)的約 13%。**不足以填上「線性預測 84%
vs 目標 90%」的六點缺口。** 定位是「一個常數的改動,成本近零、期望也低」,
不是主攻方向。

**限制**:直接捨入 MSE,不含 GPTQ 誤差補償、不含 `scale_joint` 的
Σ-加權 α 重解、不含後續訓練。只用於 c 之間的相對比較,絕對值無意義。
GPTQ 的補償通常偏好零附近細的網格,可能改變排序。

## E 自由碼本上限(Lloyd-Max):統計刻度軸封頂(追加量測,`diag_lloyd.json`)

D 量的是 Corkscrew 網格族內(c,s 兩個自由度)的最優;E 放掉全部結構
約束,對同一份 u 直方圖解 L 點對稱最優量化器(Lloyd-Max)——這是
**任何**統計調刻度方案(NF4 分位數、SqueezeLLM k-means…)的 MSE 下界:

| 檔位 | 自由碼本 RMS | 族內最優 RMS | c=0.6 RMS | 結構代價(MSE) |
|---|---|---|---|---|
| 7元 | **20.96%** | 21.55% | 22.13% | −5.4% |
| 9元 | **16.64%** | 17.02% | 17.81% | −4.4% |
| 5元 | 28.10% | — | — | — |
| 3元 | 42.95% | — | — | — |

7元 最優碼點 {0, ±0.47, ±0.99, ±1.69}:理論預期的「零附近密、尾巴疏」
確實出現(間距 0.47/0.52/0.70),但相對均勻網格的增益只有 ~2.7% RMS。

**判定:統計刻度軸整條封頂。** 從 c=0.6 走到完全自由碼本總共只買
5.3% RMS(7元),遠小於六點缺口;而自由碼本還要付出毀掉雙三元
累加器算力結構(退化為 LUT)的代價。k=2 族內的 c 重優化(D 節)
已捕獲此上限的一半以上。**幾何軸與配置軸現在都已出清,唯一開放的
是配方/課程軸。**

直方圖已落盤 `weight_hist_u.json`(8000 bins,35.7 億權重),後續
幾何探測不需再載模型。
